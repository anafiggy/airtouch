# AirTouch 品牌官网 V24 · SEO 基础版本

## 本次更新

- 保留 V23 首页视觉、动态标题、场景 Tab、案例 Tab 和飞书线索表单。
- 将约 11 MB 的单文件拆分为 HTML、CSS、JavaScript 和可缓存图片资源。
- 图片统一优化为适合网页加载的格式，并为大图生成移动端尺寸。
- 新增场景方案、碰一碰物料、客户案例和知识中心四组可独立收录页面。
- 新增 canonical、Open Graph、Organization / Service / Article 结构化数据。
- 新增 robots.txt、sitemap.xml、favicon、网站清单和隐私政策。
- 首页增加可抓取的内部链接，所有重点页面都能从首页进入。
- 保留 edge-functions/api/lead.js 和现有飞书环境变量配置。

## 部署

请把本目录中的全部文件与文件夹上传到仓库根目录。不要只上传 index.html。

正式域名确定后，请统一替换以下文件中的测试域名：

`https://airtouch-eaddgvpv.edgeone.cool`

需要替换的位置包括 HTML canonical / Open Graph、robots.txt 和 sitemap.xml。
