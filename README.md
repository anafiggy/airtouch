# AirTouch 品牌官网 V17

## 本次更新

- 首屏视觉整体右移，与左侧文字形成清晰分区，不再落在标题和正文正下方。
- NFC 圆形物料升级为带金属环和连接扣的 AirTouch 钥匙扣造型。
- 手机向右靠近钥匙扣，触碰距离更自然，手机与物料之间的关系更明确。
- 手机触碰前显示完整的系统桌面；触碰后自动打开企业官网页面，不再只显示抽象的成功提示。
- 参考轻流官网的首屏层级，在桌面端增加左右留白边界，在窄屏增加渐变遮罩，让文字和产品演示自然分开。
- 重新设计 1120px、900px、760px 和 420px 下的首屏构图，手机端不再直接压缩桌面布局。
- 完全移除 V15 通过裁切整张海报制造的首屏动效。
- 手机、NFC 物料、触碰光波和手机界面全部改为独立图层，不再出现未抠干净的背景。
- 首屏使用“靠近—识别—开启服务”的 5.8 秒状态循环，手机界面在触碰后切换为成功状态。
- 手机与物料采用浏览器原生高清图形绘制，在 Retina 和高分辨率屏幕上保持清晰，不依赖放大低清位图。
- 动效只使用位移、旋转与透明度变化，兼顾流畅度；系统开启“减少动态效果”时显示静态成功画面。
- 首屏标题升级为动态价值表达：“让一次触碰，变成”后依次输入“持续互动的入口”“继续跟进的线索”“反复触达的客户”。
- 移动端采用专门的紧凑信息架构：优势卡片和交付步骤横向滑动、场景媒体缩为双图组合、二维码隐藏，减少连续下滑距离。
- 修正手机端强制不换行导致的标题、正文和数据溢出。
- 标题在桌面端保持语义完整，在窄屏上根据可用宽度自然换行。
- 重构优势卡片、物料 Tab、场景方案、客户案例、交付流程和联系表单的手机布局。
- 为 760px、480px 和 360px 三档屏幕宽度分别设置稳定的响应式规则。
- 图片、表单控件、联系方式、案例指标和弹窗均限制在手机可视区域内。
- 导航栏改为固定在页面顶部，页面跳转或向下浏览后仍可随时使用。
- 修复移动端菜单，支持触屏开关、点击导航后收起、点击外部收起和 Esc 键关闭。
- 保留 V13 已经打通的飞书多维表格写入和群机器人通知逻辑。
- 所有网页图片已嵌入 `index.html`，无需单独上传图片目录。

## EdgeOne 部署

仓库根目录请至少保留：

```text
index.html
edge-functions/
  api/
    lead.js
```

`index.html` 为单文件前端，大小约 11 MB，低于 GitHub 网页上传 25 MB 的单文件限制。`lead.js` 负责把表单线索写入飞书多维表格并发送群通知，请继续保留现有 EdgeOne 环境变量。

## 表单错误诊断

最新版 `lead.js` 会在失败响应中附带不含密钥的诊断字段：

- `MISSING_ENVIRONMENT`：生产环境缺少必要变量。
- `FEISHU_AUTH_FAILED`：App ID 或 App Secret 无效。
- `FEISHU_BITABLE_WRITE_FAILED`：多维表格权限、App Token、Table ID、字段名称或字段类型不匹配。
- `LEAD_SUBMISSION_FAILED`：其他运行时或网络异常。

同时会返回 `providerCode` 和 `requestId`，便于进一步定位；不会返回 App Secret 或访问凭证。
